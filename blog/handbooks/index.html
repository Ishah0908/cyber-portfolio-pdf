Field Handbooks

Defensive security, written the way it actually works in the field. No vendor slides, no filler. Just what earns its place when you are the one on the hook.

Eight handbooks, each a standalone read. They cross-reference each other, but you can start anywhere. Every command is real and meant to be lab-tested before you trust it; every diagram is built to be understood, not to fill space.

> start with Zero Trust if you want the spine that ties the rest together.
